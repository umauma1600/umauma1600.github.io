## 🎮 ゲーム概要

4桁のダイヤル錠がかかった古びた宝箱。
プレイヤーはダイヤル錠を解いて宝箱を開けようとするが、実は宝箱には底がない。
固定観念を逆転させる謎解き。

**キャッチコピー**: 「常識にとらわれていませんか？」

**ポイント**: ダイヤル錠は解かなくてもクリアできる。宝箱は最初から持ち上げられる。

---

## 📖 ストーリー（挑戦状）

テーブル上の封筒をタップすると「挑戦状」として表示される。

> 親愛なる挑戦者へ
>
> ここには4桁のダイヤル錠がかかっている古びた宝箱があります。
> この宝箱の中にある紙に書かれたキーワードを送信できれば、あなたの勝利です。
>
> 固定観念を逆転させ、宝箱の中に隠されたキーワードを見つけ出してください。

## 🎯 ゲームフロー

### 画面構成

- **上部ナビ**: 「← 謎解き一覧に戻る」とプレイ時間
- **ゲームエリア**: テーブルの上に、封筒（左）・宝箱（中央）・メモ（右）
- **固定フッター**: 最終解答の入力欄、「回答」ボタン、ヒントボタン（💡）

ページ全体のスクロールは無効化している（ドラッグ操作のため）。

### 調べられるもの

| 対象 | 操作 | 内容 |
|------|------|------|
| 封筒 | タップ | 挑戦状（ストーリー）を表示 |
| メモ | タップ | ダイヤル錠の手がかりを表示（3ページ） |
| ダイヤル錠 | タップ | 4桁ダイヤルの入力画面を表示 |
| 宝箱 | ドラッグ | 持ち上げられる（最初から可能） |
| 落ちてきた紙 | タップ | 紙を開いてキーワードを表示 |

### ダイヤル錠（ミスリード）

メモの手がかりはケルナ語（[KELNA.md](KELNA.md)）で書かれている。

1. `Numek-n es n.` / `Numek-ki es wrils.` / `Numek-zam es grovinas.` / `Numek-befo es ki.`
2. 「この言語はケルナ語という言語だ」
3. 「解錠されることは想定していないようだ」

ケルナ語は数字を表す単語の文字数がそのまま数値になる（n=1、wrils=5、grovinas=8、ki=2）。
よって正解は **1582**。

- ▲▼ボタンで各桁を 0〜9 で循環させ、「OPEN」で判定する
- 正解: 「✅ 錠が開きました！」と表示し、約1.5秒後に入力画面を閉じて錠がフェードアウトする
- 不正解: 「❌ 番号が違うようです...」と表示する
- **錠を外しても宝箱は開かない**

### 真の解法

1. 宝箱を**上にドラッグ**して持ち上げる（30px 以上動かすとドラッグ扱い）
2. 50px 以上持ち上げると、宝箱のあった位置に折りたたまれた紙が現れる
3. 指を離すと宝箱は落下してテーブルに戻る（左右位置は保持、テーブル幅の範囲内）
4. 紙をタップ → 「どうやら宝箱の底が抜けていたようだ」→ タップで紙が開く
5. 開いた紙に「正解のキーワード」として **逆転の発想** と書かれている

### 最終解答

- フッターの入力欄に入力し、「回答」ボタンまたは Enter で判定
- 正解: `逆転の発想` / `ぎゃくてんのはっそう` / `ギャクテンノハッソウ`（前後の空白は無視）
- 不正解: 「❌ 違うようです...もう一度考えてみましょう。」と表示し、入力欄が揺れる

### クリア演出

- 紙吹雪、キラキラ、「CLEAR!」リボン、やまーたの画像
- 「おめでとう！」「『逆転の宝箱』をクリアしました！」
- クリアタイム（タイマーはクリア時点で停止）
- ボタン: 「𝕏 でシェア」「謎解き一覧に戻る」「もう一度挑戦」（ページ再読み込み）

シェア文面:

```
「逆転の宝箱」をクリアしました！⏱️ {クリアタイム}
固定観念を逆転させる謎解きに挑戦しよう！
#ひみつ箱のアトリエ
```

## 💡 ヒント

ヒントボタンから、いつでも全10段階を「前のヒント」「次のヒント」で行き来できる（表示条件や時間制限はない）。

| # | 内容 |
|---|------|
| 1 | ヒントの使い方の説明 |
| 2 | ダイヤル錠を開けるための手がかりは大変難しい |
| 3 | 「ケルナ語」とは架空の言語 |
| 4 | 手がかりの日本語訳（最初の数字は1、2番目は5、3番目は8、4番目は2） |
| 5 | ダイヤル錠の番号は「1582」 |
| 6 | 解錠しても宝箱は開かない。逆転の発想が必要 |
| 7 | 宝箱自体に何か仕掛けがあるかもしれない |
| 8 | この宝箱は最初から机に置いてあった |
| 9 | 宝箱の底がない可能性を考える |
| 10 | 宝箱を上に持ち上げれば中の紙が見つかる |

## 🎨 デザイン

- サイト共通のカラーパレットを使用
  - `--color-primary: #3d2f23`（ウォームブラウン）
  - `--color-accent: #c69c6d`（ゴールデンベージュ）
  - `--color-bg: #faf8f5`（アイボリー）
- テーブル・宝箱・ダイヤル錠・封筒・メモ・紙はすべて画像（WebP）
- 挑戦状とメモは紙風のモーダル、ダイヤルは濃いグレーの筐体に白い数字窓

### レスポンシブ

| | モバイル（〜768px） | デスクトップ（769px〜） |
|---|---|---|
| テーブル幅 | 90% | 70%（最大 800px） |
| 宝箱 | `w-32` | `w-40` |
| 封筒・メモ | 85% に縮小 | 等倍 |

マウスとタッチの両方でドラッグできる。

## 🔧 技術メモ

- React の関数コンポーネント1つで完結（状態は `useState` / `useRef`）
- スタイルは Tailwind CSS とコンポーネント内の `<style>`
- 調整用の数値は `CONSTANTS` にまとめている

| 定数 | 値 | 用途 |
|------|----|------|
| `DRAG_THRESHOLD` | 30px | ドラッグ開始とみなす移動量 |
| `PAPER_SHOW_THRESHOLD` | 50px | 紙が現れる持ち上げ量 |
| `FALL_DURATION_BASE` / `MAX` | 0.3秒 / 0.6秒 | 宝箱の落下時間 |
| `CONFETTI_COUNT` | 100 | 紙吹雪の数 |
| `PAPER_OPENING_DELAY` | 800ms | 紙が開く演出の長さ |
| `TIMER_INTERVAL` | 1000ms | プレイ時間の更新間隔 |
