## 🎮 ゲーム概要

4桁のダイヤル錠がかかった古びた宝箱。
プレイヤーはダイヤル錠を解いて宝箱を開けようとするが、実は宝箱には底がない。
固定観念を逆転させる謎解き。

**キャッチコピー**: 「常識にとらわれていませんか？」

**ポイント**: ダイヤル錠は解かなくてもクリアできる。宝箱は最初から持ち上げられる。

---

## 📖 ストーリー（挑戦状）

ページを開くと最初に「挑戦状」が表示される。閉じるとゲーム開始（タイマーもここから動く）。
机の上の封筒をタップすればいつでも読み返せる。

> 親愛なる挑戦者へ
>
> ここには4桁のダイヤル錠がかかっている古びた宝箱があります。
> この宝箱の中にある紙に書かれたキーワードを送信できれば、あなたの勝利です。
>
> 固定観念を逆転させ、宝箱の中に隠されたキーワードを見つけ出してください。

## 🎯 ゲームフロー

### 画面構成

ランプの灯る部屋で、机に向かっている一人称の構図。画面全体を使い、ページはスクロールしない。

- **ヘッダー**: 「← 一覧へ」、タイトル、プレイ時間
- **場面**: 机の奥中央に宝箱、手前左に封筒、手前右にメモ。場面の下端にナレーション（ひとこと）が出る
- **フッター**: 最終解答の入力欄、「回答」ボタン、ヒントボタン

### 調べられるもの

| 対象 | 操作 | 内容 |
|------|------|------|
| 封筒 | タップ | 挑戦状（ストーリー）を表示 |
| メモ | タップ | ダイヤル錠の手がかりを表示（3ページ） |
| ダイヤル錠 | タップ | 4桁ダイヤルの入力画面を表示 |
| 宝箱 | タップ | ガタガタ揺れて「蓋は開かない」とナレーション |
| 宝箱 | ドラッグ／上矢印キー | 持ち上げられる（最初から可能） |
| 落ちてきた紙 | タップ | 丸められた紙を広げてキーワードを表示 |

### ダイヤル錠（ミスリード）

メモの手がかりはケルナ語（[KELNA.md](KELNA.md)）で書かれている。

1. `Numek-n es n.` / `Numek-ki es wrils.` / `Numek-zam es grovinas.` / `Numek-befo es ki.`
2. 「この言語はケルナ語という言語だ」
3. 「解錠されることは想定していないようだ」

ケルナ語は数字を表す単語の文字数がそのまま数値になる（n=1、wrils=5、grovinas=8、ki=2）。
よって正解は **1582**。

- ▲▼ボタンで各桁を 0〜9 で循環させ、「OPEN」で判定する。合わせた数字は宝箱に掛かっている錠にもそのまま表示される
- 正解: 「カチッ。錠が開きました！」と表示し、約1秒後に入力画面を閉じる。錠は宝箱から外れて落ち、「錠は外れた。……しかし、蓋はびくともしない。」とナレーション
- 不正解: 「番号が違うようです……」と表示し、ダイヤルが揺れる
- **錠を外しても宝箱は開かない**

### 真の解法

1. 宝箱を**上にドラッグ**して持ち上げる（6px 以上動かすとドラッグ扱い。左右にも動かせる）
2. 36px 以上持ち上げると、底のない宝箱から、くしゃっと丸められた紙が机に落ちる（宝箱の手前に落ちるので、宝箱を戻しても隠れない）
3. 指を離すと宝箱は落下して机に戻る（左右位置は保持、場面の範囲内）
4. 紙をタップ → 「どうやら宝箱の底が抜けていたようだ」→ タップで丸められた紙が広がる（しわの残った一枚の紙になる）
5. 開いた紙に「正解のキーワード」として **逆転の発想** と書かれている
6. 「キーワードを解答する」で紙を閉じると、解答欄にキーワードが自動で入力され、フォーカスが移る（あとは「回答」を押すだけ）

### 最終解答

- フッターの入力欄に入力し、「回答」ボタンまたは Enter で判定
- 正解: `逆転の発想` / `ぎゃくてんのはっそう` / `ギャクテンノハッソウ`（空白は無視）
- 不正解: 「違うようです……もう一度考えてみましょう。」と表示し、入力欄が揺れる

### クリア演出

- 紙吹雪、「CLEAR!」リボン、やまーたの画像
- 「おめでとう！」「『逆転の宝箱』をクリアしました！」
- クリアタイム（挑戦状を閉じてから正解するまで）
- ボタン: 「𝕏 でシェア」「謎解き一覧に戻る」「もう一度挑戦」（ページを再読み込みせず、最初の状態に戻す）

シェア文面:

```
「逆転の宝箱」をクリアしました！⏱️ {クリアタイム}
固定観念を逆転させる謎解きに挑戦しよう！
#ひみつ箱のアトリエ
```

## 💡 ヒント

ヒントボタンから、いつでも全10段階を「前のヒント」「次のヒント」で行き来できる（表示条件や時間制限はない）。

| # | 内容 |
|---|------|
| 1 | ヒントの使い方の説明 |
| 2 | ダイヤル錠を開けるための手がかりは大変難しい |
| 3 | 「ケルナ語」とは架空の言語 |
| 4 | 手がかりの日本語訳（最初の数字は1、2番目は5、3番目は8、4番目は2） |
| 5 | ダイヤル錠の番号は「1582」 |
| 6 | 解錠しても宝箱は開かない。逆転の発想が必要 |
| 7 | 宝箱自体に何か仕掛けがあるかもしれない |
| 8 | この宝箱は最初から机に置いてあった |
| 9 | 宝箱の底がない可能性を考える |
| 10 | 宝箱を上に持ち上げれば中の紙が見つかる |

## 🎨 デザイン

- ゲーム画面は暗めの部屋（焦げ茶）にランプの光、という専用の雰囲気。モーダルやボタンはサイト共通のアイボリー／ゴールデンベージュ
- 机・宝箱・ダイヤル錠・封筒・メモ・紙・ランプはすべて同じタッチの SVG（焦げ茶の主線 + ブラウン／ゴールド系）
- 挑戦状は便箋風、メモは罫線入りのメモ用紙風、ダイヤルは真鍮の筐体に黒い数字窓

### レスポンシブ

机まわりは「横 100 × 縦 125」の独自単位 `--u` で配置し、場面（ヘッダーとフッターの間）の幅・高さのどちらにも収まるように伸縮する（1u は最大 5.6px、つまり机まわりは最大 560px 幅）。机の天板は画面の横幅いっぱいに広がる。

マウス・タッチ・ペンのいずれでもドラッグできる（Pointer Events）。

## 🔧 技術メモ

`src/pages/treasure-box/` の構成:

| ファイル | 役割 |
|----------|------|
| `TreasureBoxPage.tsx` | ページ本体。進行状況の状態と場面の配置 |
| `modals.tsx` | 挑戦状・メモ・ダイヤル錠・ヒント・紙・クリアの各モーダル |
| `useChestLift.ts` | 宝箱をつかんで持ち上げる操作（ドラッグ・落下・キーボード） |
| `art.tsx` | SVG イラスト |
| `data.tsx` | 正解・メモ・ヒントの文面、時間の整形 |
| `treasure-box.css` | スタイル（クラス名は `tb-` 始まり） |

| 定数 | 値 | 用途 |
|------|----|------|
| `DRAG_START_PX` | 6px | ドラッグ開始とみなす移動量 |
| `PAPER_REVEAL_LIFT` | 36px | 紙が落ちる持ち上げ量 |
| `FALL_MS` | 260ms | 宝箱の落下時間（CSS の transition と揃える） |
| `KEY_LIFT_PX` / `KEY_HOLD_MS` | 90px / 700ms | 上矢印キーで持ち上げる高さと時間 |
| `CAPTION_MS` | 4500ms | ナレーションの表示時間 |
| `UNLOCK_DELAY_MS` | 1100ms | 解錠してから入力画面を閉じるまで |

クリア画面のやまーたは `public/assets/images/yama-tahappy.webp`。
